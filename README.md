
# SmartHMS - Smart Hospital Management System

## About the Project
SmartHMS is a Hospital Management System designed to simplify and manage hospital operations digitally.

## Features
- Patient Management
- Hospital Data Management
- Database Integration

## Technologies Used
- Python
- Java
- SQL
- Maven

## Project Structure
- main.py
- pom.xml
- requirements.txt
- schema.sql
- seed.sql

## Installation
1. Clone this repository.
2. Install the required dependencies.
3. Configure the database.
4. Run the application.
